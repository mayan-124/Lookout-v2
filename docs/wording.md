# Lookout wording

One word for one meaning, on every screen, in help and in messages.

## Actions

| Word | Means | Notes |
|---|---|---|
| Open | Start an app, or show a file, folder, link or page. | |
| Show in folder | Show a file or folder in File Explorer. | Ctrl+E. Never "Reveal". |
| Copy | Put the row's text on the clipboard. | Ctrl+C. |
| Copy path | Copy a file's or folder's address. | Ctrl+C on files. |
| Copy file | Put the file itself on the clipboard. | Ctrl+Shift+C. |
| Paste | Copy a clip and paste it into the app you were in. | |
| Delete | Destroy something Lookout keeps: a note, clip, quick key, saved search, saved scan, your data. | Delete key; Undo where it exists. |
| Remove | Take an entry off a list. The thing itself stays. | A folder you search, a filter. |
| Move to Recycle Bin | Send files to the Windows Recycle Bin. | Never plain "Delete" for these. |
| Clean | Run one Disk clean-up entry. | |
| Cancel | Stop something running or waiting: a timer, a scan, a question. | |
| Stop | End a program that holds a port. | |
| Undo | Take back the last change. | |
| Pause / Resume | Hold and continue recording and background work. | |
| Close | Leave a page or card. | Esc. |
| Dismiss | Hide a message. | |
| Skip | Leave something out: a folder, a setup step. | |
| Scan / Scan again | Look at a drive or folder; look again. | Never "Rescan". |
| Choose folder | Pick the one place to work on. | |
| Add folder | Add a place to a list. | |
| Reset | Return settings to their starting values. Your data stays. | |

## Things

| Word | Means | Not |
|---|---|---|
| shortcut | A key combination, such as Alt+Space. | hotkey |
| quick key | A short word that puts one result first. | alias |
| link | A web address. In Disk, also a folder that points elsewhere. | shortcut folder |
| add-on | An optional part, turned on in Settings. | plugin (code and developer documents only) |
| clip | One entry of the clipboard history. | item |
| search data | What Lookout stored about your files. | |

## Feature families

The same five names head help and the registry (`ui/src/registry.json`), choose the Home tip icons and group
Settings > Features.

| Family | Features |
|---|---|
| Find | files and apps, Text in pictures, operators, date filters, By meaning, web and network paths, quick keys |
| Capture | screenshot, scrolling capture, screen recording, Text from screen, Clipboard |
| Everyday | calculator, units, dates, time zones, timers, notes |
| This PC | Disk analyzer, ports, Windows settings, dark mode, command line |
| Lookout | settings, theme, privacy, setup, help |

## Feature names

| Name | Means | Not |
|---|---|---|
| Disk analyzer | The page that shows what uses space. Its dock button is "Disk". | Disk usage |
| Clipboard | The feature. Its stored entries are the clipboard history. | Clipboard history (as a name) |
| Text in pictures | Searching for text inside images (Find). | Words in pictures |
| Text from screen | Copying text out of a part of the screen (Capture). | Extract text, grab text (typed commands still work) |
